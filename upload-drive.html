⚠️ Configuration requise

  1. Installer Ruby et les dépendances : 
    bundle install
  2. Obtenir les credentials Google :
    • Allez sur Google Cloud Console
    • Créez un projet et activez l'API Google Drive
    • Créez des identifiants OAuth 2.0
    • Téléchargez le fichier JSON et renommez-le en credentials.json
    • Placez-le dans le dossier du projet
  3. Lancer le script Ruby : 
    ruby upload_to_drive.rb
💡 Note : Cette page HTML est une interface visuelle. Pour uploader réellement vers Google Drive, vous devez utiliser le script Ruby upload_to_drive.rb dans votre terminal. Consultez GUIDE-GOOGLE-DRIVE.md pour les instructions complètes.
